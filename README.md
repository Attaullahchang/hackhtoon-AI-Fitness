# AI Fitness Coach UI

Responsive React/Vite recreation inspired by the provided AI Fitness Coach screenshots and reference site.

## Included

- Landing page
- User/Admin sign-in mode
- Registration page
- Responsive user dashboard with charts and KPI cards
- AI Coach mock chat
- Workout generator
- Nutrition plan
- Workout library with search
- Progress tracking
- Progress photo upload preview
- Notifications
- Profile/settings
- Admin dashboard
- Users, analytics, AI usage, AI/system logs, moderation, workouts, notifications and settings
- Mobile sidebar/navigation
- Mock/local demo data only; backend API can be connected later

## Requirements

- Node.js 18+ (Node 20+ recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

Then open the URL Vite shows in the terminal, normally:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
npm run preview
```

## Demo navigation

- `/` landing page
- `/login` sign in
- `/register` create account
- `/dashboard` user dashboard
- `/admin` admin console

The login is a frontend demo. Choose **User** or **Admin** and click **Sign in**; no real authentication server is required.
